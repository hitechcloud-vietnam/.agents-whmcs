# WHMCS Domain Redirect Devkit

## Overview
Domain URL forwarding and redirect management.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- URL redirects
- 301/302 redirects
- Path forwarding
- Wildcard redirects

## Installation
Upload to `/modules/addons/` and activate.
