# WHMCS Client Portal Customizer Devkit

## Overview
Customize the client portal with branding, layout options, and enhanced user experience features.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom branding
- Layout options
- Widget customization
- Theme options
- Navigation customization

## Installation
Upload to `/modules/addons/` and activate.
