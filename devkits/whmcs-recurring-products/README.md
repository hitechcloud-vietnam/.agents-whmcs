# WHMCS Recurring Products Devkit

## Overview
Advanced recurring billing management with custom cycles, proration, and renewal handling.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom billing cycles
- Proration calculations
- Renewal management
- Grace periods
- Recurring analytics

## Installation
Upload to `/modules/addons/` and activate.
