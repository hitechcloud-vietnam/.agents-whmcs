# WHMCS Coupon System Devkit

## Overview
Full-featured coupon management system with code generation, usage tracking, restrictions, and promotional campaigns.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom coupon code generation
- Usage limits and tracking
- Product/category restrictions
- Date-based validity
- Customer-specific coupons
- Single/multiple use
- Coupon analytics

## Installation

### Step 1: Upload
Upload to `/modules/addons/whmcs-coupon-system/`

### Step 2: Activate
**Setup > Addon Modules** > Activate

### Step 3: Usage
Navigate to module for coupon management
