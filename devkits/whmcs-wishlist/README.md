# WHMCS Wishlist Devkit

## Overview
Customer wishlist functionality with sharing, price alerts, and wishlist analytics.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Add to wishlist
- Wishlist sharing
- Price drop alerts
- Stock notifications
- Wishlist analytics

## Installation
Upload to `/modules/addons/` and activate.
