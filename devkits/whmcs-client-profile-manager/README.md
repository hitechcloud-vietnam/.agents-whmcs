# WHMCS Client Profile Manager Devkit

## Overview
Enhanced client profile management with custom fields, verification status, and profile completeness tracking.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom profile fields
- Profile completeness
- Verification badges
- Profile history
- Privacy settings

## Installation
Upload to `/modules/addons/` and activate.
