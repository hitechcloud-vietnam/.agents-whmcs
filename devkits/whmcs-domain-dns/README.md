# WHMCS Domain DNS Devkit

## Overview
Domain DNS record management with custom DNS entries.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- DNS record management
- A/AAAA/CNAME/MX/TXT records
- TTL control
- Default record templates

## Installation
Upload to `/modules/addons/` and activate.
