# WHMCS Configuration Options Devkit

## Overview
Advanced product configuration options with conditional logic, pricing modifiers, and visual selectors.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom option types
- Conditional logic
- Price modifiers
- Multi-select options
- Option dependencies
- Visual config builders

## Installation
Upload to `/modules/addons/` and activate.
