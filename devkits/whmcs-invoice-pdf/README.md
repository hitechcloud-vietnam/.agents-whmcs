# WHMCS Invoice PDF Devkit

## Overview
Custom PDF invoice generation with professional layouts and branding.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom PDF layouts
- Company branding
- Multi-page support
- Barcode/QR support

## Installation
Upload to `/modules/addons/` and activate.
