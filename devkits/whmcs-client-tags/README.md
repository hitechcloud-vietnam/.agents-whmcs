# WHMCS Client Tags Devkit

## Overview
Tag management system for clients with custom tags, auto-tagging rules, and tag-based filtering.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom tags
- Tag categories
- Auto-tagging rules
- Tag-based filtering
- Tag analytics

## Installation
Upload to `/modules/addons/` and activate.
