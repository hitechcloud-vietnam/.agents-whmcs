# WHMCS Client Search Devkit

## Overview
Advanced client search with filters, saved searches, search analytics, and real-time results.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Advanced filters
- Saved searches
- Search analytics
- Real-time results
- Search suggestions

## Installation
Upload to `/modules/addons/` and activate.
