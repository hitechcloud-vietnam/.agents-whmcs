# WHMCS Invoice Reminders Devkit

## Overview
Automated invoice reminder system with customizable schedules and multiple reminder types.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Automated reminders
- Multiple schedules
- Email templates
- Reminder analytics

## Installation
Upload to `/modules/addons/` and activate.
