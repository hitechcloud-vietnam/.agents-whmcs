# WHMCS Client Import Export Devkit

## Overview
Bulk import/export clients with CSV support, field mapping, validation, and scheduled imports.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- CSV import/export
- Field mapping
- Data validation
- Scheduled imports
- Import history

## Installation
Upload to `/modules/addons/` and activate.
