# WHMCS Tiered Pricing Devkit

## Overview
Multi-level pricing tiers with customer-based pricing and custom tier management.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Multi-level tiers
- Customer-specific pricing
- Tier comparison
- Auto-upgrade tiers
- Tier reports

## Installation
Upload to `/modules/addons/` and activate.
