# WHMCS Product Groups Devkit

## Overview
Organize products into groups with custom layouts, group-based pricing, and group navigation.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom product groups
- Group-based pricing
- Group navigation
- Featured products
- Group themes

## Installation
Upload to `/modules/addons/` and activate.
