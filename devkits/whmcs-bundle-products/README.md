# WHMCS Bundle Products Devkit

## Overview
Create and manage product bundles with combined pricing, cross-sell bundles, and bundle analytics.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Bundle creation wizard
- Combined pricing
- Bundle restrictions
- Component selection
- Bundle templates
- Cross-sell bundles

## Installation
Upload to `/modules/addons/whmcs-bundle-products/` and activate
