# WHMCS Client Verification Devkit

## Overview
Client identity verification with document upload, verification status, and KYC compliance.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Identity verification
- Document upload
- Verification status
- KYC compliance

## Installation
Upload to `/modules/addons/` and activate.
