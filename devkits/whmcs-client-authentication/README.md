# WHMCS Client Authentication Devkit

## Overview
Enhanced client authentication with custom login methods, SSO integration, and authentication policies.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom login methods
- SSO integration
- Authentication policies
- Login restrictions

## Installation
Upload to `/modules/addons/` and activate.
