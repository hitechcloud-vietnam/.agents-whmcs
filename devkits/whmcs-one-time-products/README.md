# WHMCS One-Time Products Devkit

## Overview
Manage one-time purchase products with setup fees, license keys, and instant delivery.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- One-time billing
- Setup fees
- License key generation
- Instant delivery
- Download management

## Installation
Upload to `/modules/addons/` and activate.
