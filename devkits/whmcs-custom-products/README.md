# WHMCS Custom Products Devkit

## Overview
Create custom product types with dynamic fields, pricing logic, and unique fulfillment workflows.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom product types
- Dynamic fields
- Custom pricing logic
- Unique workflows
- Custom fulfillment

## Installation
Upload to `/modules/addons/` and activate.
