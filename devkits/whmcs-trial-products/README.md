# WHMCS Trial Products Devkit

## Overview
Manage trial products with automatic conversion, trial limits, and reminder notifications.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Trial periods
- Automatic conversion
- Trial limits
- Reminder emails
- Conversion tracking

## Installation
Upload to `/modules/addons/` and activate.
