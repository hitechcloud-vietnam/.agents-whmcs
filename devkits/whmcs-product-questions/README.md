# WHMCS Product Questions Devkit

## Overview
Add custom questions to products with conditional logic, file uploads, and response management.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom questions
- Question types
- Conditional logic
- File uploads
- Response tracking

## Installation
Upload to `/modules/addons/` and activate.
