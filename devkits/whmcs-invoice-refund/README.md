# WHMCS Invoice Refund Devkit

## Overview
Process invoice refunds with multiple refund methods and tracking.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Refund processing
- Multiple methods
- Partial refunds
- Refund tracking

## Installation
Upload to `/modules/addons/` and activate.
