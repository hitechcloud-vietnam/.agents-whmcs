# WHMCS Client Impersonation Devkit

## Overview
Staff client impersonation for support with audit logging and session restrictions.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Staff impersonation
- Session restrictions
- Audit logging
- Impersonation alerts

## Installation
Upload to `/modules/addons/` and activate.
