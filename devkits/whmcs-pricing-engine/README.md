# WHMCS Pricing Engine Devkit

## Overview
Advanced pricing management with dynamic pricing rules, cost-plus markup, competitor matching, and flexible pricing strategies.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Cost-plus pricing
- Dynamic markup rules
- Volume discounts
- Time-based pricing
- Competitor price matching
- Currency-based pricing
- Cost tier management

## Installation

### Step 1: Upload Files
Upload to `/modules/addons/whmcs-pricing-engine/`

### Step 2: Activate
Navigate to **Setup > Addon Modules** and activate

### Step 3: Configure Pricing Rules
Access module to set up pricing strategies
