# WHMCS Client API Keys Devkit

## Overview
Client API key management with key generation, scopes, and usage monitoring.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- API key generation
- Scopes and permissions
- Usage monitoring
- Key rotation

## Installation
Upload to `/modules/addons/` and activate.
