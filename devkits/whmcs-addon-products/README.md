# WHMCS Addon Products Devkit

## Overview
Manage product addons with optional enhancements, dependency management, and addon recommendations.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Addon creation and management
- Dependency rules
- Auto-recommend addons
- Bundle addons with products
- Addon pricing tiers

## Installation
Upload to `/modules/addons/` and activate.
