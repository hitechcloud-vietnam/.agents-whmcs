# WHMCS Invoice Customizer Devkit

## Overview
Customize invoice appearance with branding, layout options, and custom fields.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom branding
- Layout options
- Custom fields
- Color schemes
- Logo placement

## Installation
Upload to `/modules/addons/` and activate.
