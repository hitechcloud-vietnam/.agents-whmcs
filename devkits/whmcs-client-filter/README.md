# WHMCS Client Filter Devkit

## Overview
Advanced client filtering with multiple criteria, filter presets, and real-time filtering.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Multi-criteria filters
- Filter presets
- Real-time filtering
- Custom filter fields
- Filter history

## Installation
Upload to `/modules/addons/` and activate.
