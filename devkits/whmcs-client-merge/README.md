# WHMCS Client Merge Devkit

## Overview
Merge duplicate client accounts with field mapping, history preservation, and conflict resolution.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Duplicate detection
- Account merging
- History preservation
- Conflict resolution
- Merge audit log

## Installation
Upload to `/modules/addons/` and activate.
