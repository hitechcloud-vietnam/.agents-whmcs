# WHMCS Client Delete Devkit

## Overview
Safe client deletion with data backup, cascade handling, and deletion confirmation.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Data backup before deletion
- Cascade handling
- Deletion confirmation
- Deletion audit log

## Installation
Upload to `/modules/addons/` and activate.
