# WHMCS Discount Manager Devkit

## Overview
Comprehensive discount management with automatic discounts, promotional pricing, customer-specific discounts, and discount scheduling.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Automatic discount rules
- Time-based promotions
- Customer tier discounts
- Product-specific discounts
- Category discounts
- Discount stacking options
- Discount reports

## Installation

### Step 1: Upload Files
Upload to `/modules/addons/`

### Step 2: Activate
**Setup > Addon Modules** > Activate

### Step 3: Configure
Set up discount rules and promotional schedules
