# WHMCS Client Dashboard Devkit

## Overview
Enhanced client dashboard with widgets, analytics, quick actions, and customizable layout.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Dashboard widgets
- Usage analytics
- Quick actions
- Recent activity
- Custom widgets

## Installation
Upload to `/modules/addons/` and activate.
