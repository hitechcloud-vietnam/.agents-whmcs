# WHMCS Client Bulk Actions Devkit

## Overview
Bulk client management with batch operations, action queues, and undo capabilities.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Batch operations
- Action queues
- Undo capability
- Bulk status changes
- Bulk email

## Installation
Upload to `/modules/addons/` and activate.
