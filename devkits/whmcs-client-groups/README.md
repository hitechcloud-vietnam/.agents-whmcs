# WHMCS Client Groups Devkit

## Overview
Advanced client grouping with custom groups, group-based pricing, and group permissions.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom client groups
- Group-based pricing
- Group permissions
- Auto-assignment rules
- Group analytics

## Installation
Upload to `/modules/addons/` and activate.
