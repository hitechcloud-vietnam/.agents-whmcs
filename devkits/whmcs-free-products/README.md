# WHMCS Free Products Devkit

## Overview
Manage free products with optional upsells, download limits, and promotional offers.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Zero-price products
- Download limits
- Optional upsells
- Promotional offers
- Free tier products

## Installation
Upload to `/modules/addons/` and activate.
