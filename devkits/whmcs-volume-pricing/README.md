# WHMCS Volume Pricing Devkit

## Overview
Tiered pricing based on quantity with volume discounts and bulk pricing tables.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Quantity-based tiers
- Volume discount tables
- Bulk pricing
- Tier labels
- Savings calculator

## Installation
Upload to `/modules/addons/` and activate.
