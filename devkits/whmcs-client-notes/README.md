# WHMCS Client Notes Devkit

## Overview
Enhanced client notes system with categories, timestamps, visibility controls, and note templates.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Note categories
- Timestamps
- Visibility controls
- Note templates
- Client history

## Installation
Upload to `/modules/addons/` and activate.
