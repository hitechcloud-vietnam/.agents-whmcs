# WHMCS Invoice Generator Devkit

## Overview
Custom invoice generation with line items, taxes, discounts, and multiple currency support.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Custom line items
- Tax calculations
- Discount support
- Multi-currency
- Invoice templates

## Installation
Upload to `/modules/addons/` and activate.
