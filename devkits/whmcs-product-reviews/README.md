# WHMCS Product Reviews Devkit

## Overview
Product review system with ratings, moderation, and review analytics.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Star ratings
- Review moderation
- Verified purchaser badges
- Review analytics
- Helpful votes

## Installation
Upload to `/modules/addons/` and activate.
