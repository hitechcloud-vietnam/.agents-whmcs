# WHMCS Client 2FA Devkit

## Overview
Two-factor authentication for clients with multiple 2FA methods and backup codes.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Multiple 2FA methods
- Backup codes
- TOTP support
- SMS 2FA

## Installation
Upload to `/modules/addons/` and activate.
