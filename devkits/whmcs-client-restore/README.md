# WHMCS Client Restore Devkit

## Overview
Restore archived or deleted clients with data recovery and account reactivation.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Archive restoration
- Data recovery
- Account reactivation
- Restore history

## Installation
Upload to `/modules/addons/` and activate.
