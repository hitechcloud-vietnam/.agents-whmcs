# WHMCS Product Builder Devkit

## Overview
A visual product builder module for creating complex product configurations with custom options, pricing tiers, and dependencies.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Drag-and-drop product builder
- Custom option groups
- Pricing matrix configuration
- Product dependencies
- Conditional logic
- Bundle creation
- Product templates

## Installation

### Step 1: Upload Files
Upload the module folder to `/modules/addons/`

### Step 2: Activate
Navigate to **Setup > Addon Modules** and activate "Product Builder"

### Step 3: Configure
Access module settings to define default options and pricing rules
