# WHMCS Client Archive Devkit

## Overview
Archive inactive clients with data preservation, searchable archive, and restore capabilities.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- Archive inactive clients
- Data preservation
- Searchable archive
- Restore capability
- Archive reports

## Installation
Upload to `/modules/addons/` and activate.
