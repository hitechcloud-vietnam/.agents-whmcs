# WHMCS Product Attachments Devkit

## Overview
Manage product attachments with file versioning, download tracking, and access controls.

## WHMCS Version
- **Supported**: 7.8.0+
- **Minimum**: 7.0.0

## Features
- File attachments
- Version management
- Download tracking
- Access controls
- Automatic delivery

## Installation
Upload to `/modules/addons/` and activate.
