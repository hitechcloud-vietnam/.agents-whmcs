# WHMCS Report Tax Workflow

## Purpose
Generate tax-related reports for compliance and filing.

## Tax Report Access

### Navigation
1. Navigate to: Reports > Tax
2. Select report type
3. Set parameters

### Report Types
```
Available:
- Tax Collected
- Tax Paid
- Tax Liability
- Sales Tax Summary
```

## Tax Collected Report

### Summary
```
Shows:
- Tax collected by period
- Tax by jurisdiction
- Tax by product
- Adjustments
```

### Breakdown
```
By:
- Tax type (VAT, GST, Sales)
- Jurisdiction (State, Country)
- Product category
```

## Tax Liability Report

### Outstanding

### Calendar
