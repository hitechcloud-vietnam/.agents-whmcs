# WHMCS Client Verification Workflow

## Purpose
Step-by-step guide for verifying client identity in WHMCS.

## Prerequisites
- Client account exists
- Verification documents available
- Verification policy configured
- Staff trained on verification

## Workflow Steps

### Step 1: Verification Request
- Client submits verification request
- Identify required documents
- Set verification level
- Document request

### Step 2: Document Collection
- Request ID document
- Collect proof of address
- Gather additional documents
- Verify document validity

### Step 3: Document Review
- Review submitted documents
- Verify authenticity
- Check expiration dates
- Validate information consistency

### Step 4: Information Cross-Reference
- Compare documents to account
- Verify name matches
- Check address consistency
- Validate phone number

### Step 5: Verification Checks
- Run against verification databases
- Check for fraud flags
- Verify PEP/Sanctions status
- Run address validation

### Step 6: Risk Assessment
- Evaluate verification results
- Calculate risk score
- Identify concerns
- Determine verification status

### Step 7: Approval/Denial
- Approve verification
- Deny verification
- Request additional info
- Escalate to compliance

### Step 8: Status Update
- Update verification status
- Record verification date
- Document verification level
- Update client notes

### Step 9: Client Notification
- Notify of verification result
- Provide next steps
- Explain denial reasons (if applicable)
- Offer appeal process (if denied)

### Step 10: Documentation
- Archive verification documents
- Log verification details
- Record decision rationale
- Update compliance records

## Verification Levels
- Basic: Email + phone
- Standard: + ID document
- Enhanced: + address proof + additional checks

## Verification Documents
- Government ID (passport, driver's license)
- Utility bill
- Bank statement
- Credit card statement

## Verification Checklist
- [ ] Documents collected
- [ ] Documents reviewed
- [ ] Checks completed
- [ ] Status updated
- [ ] Client notified
- [ ] Documented
