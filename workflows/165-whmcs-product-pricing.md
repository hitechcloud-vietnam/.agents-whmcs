# WHMCS Product Pricing Setup Workflow

## Purpose
Step-by-step guide for configuring product pricing.

## Prerequisites
- WHMCS admin access
- Product created
- Pricing strategy defined

## Step 1: Access Pricing Section
- Navigate to Product > Pricing
- Select product
- View pricing configuration

## Step 2: Configure Billing Cycles
Set pricing for each cycle:
- Monthly
- Quarterly
- Semi-Annual
- Annual
- Biennial
- Triennial
- Custom cycles

## Step 3: Set Pricing Levels
Enter pricing:
- Setup fee (first time)
- Recurring price per cycle
- Currency selection
- Tax inclusive/exclusive

## Step 4: Configure Pricing Options
- Allow recurring: Yes/No
- Free trial period
- First payment different
- Hide pricing on order form
- Show from price

## Step 5: Set Affiliate Commission
- Enable affiliate commision
- Set percentage
- Set flat fee
- Configure per billing cycle

## Step 6: Multi-Currency Pricing
- Enable multi-currency
- Set prices per currency
- Configure exchange rates
- Set regional pricing

## Step 7: Promotional Pricing
- Set sale price
- Define promotion period
- Configure discount code
- Set promotional end date

## Step 8: Save Pricing
- Review all pricing
- Verify calculations
- Click "Save"
- Pricing applied to orders

## Pricing Strategies
- Cost-plus pricing
- Competitive pricing
- Value-based pricing
- Penetration pricing
- Premium pricing
