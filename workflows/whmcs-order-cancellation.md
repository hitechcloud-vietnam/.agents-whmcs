# WHMCS Order Cancellation Workflow

## Purpose
Step-by-step guide for cancelling orders in WHMCS.

## Prerequisites
- Active order
- Cancellation request received
- Authorization verified
- Outstanding items assessed

## Workflow Steps

### Step 1: Cancellation Request
- Receive cancellation request
- Identify order
- Verify requestor identity
- Document cancellation reason

### Step 2: Order Review
- Review order details
- Check current status
- Identify services affected
- Assess cancellation impact

### Step 3: Eligibility Check
- Check cancellation policy
- Verify within cancellation period
- Review contract terms
- Assess refund eligibility

### Step 4: Financial Review
- Check payment status
- Calculate refund amount
- Apply cancellation fees
- Determine net refund

### Step 5: Service Impact
- List affected services
- Plan service cancellation
- Assess server impact
- Prepare termination

### Step 6: Approval Process
- Verify authorization
- Route for approval
- Document approval
- Set conditions

### Step 7: Cancellation Execution
- Change order status
- Cancel services
- Process termination
- Update records

### Step 8: Refund Processing
- Calculate refund amount
- Process refund to original payment
- Apply credits if applicable
- Record refund transaction

### Step 9: Notification
- Send cancellation confirmation
- Explain refund details
- Provide timeline
- Include data retention info

### Step 10: Documentation
- Log cancellation details
- record reason and approval
- document refund
- update audit trail

## Cancellation Policies
- No refund: within policy
- Full refund: within cancellation period
- Partial refund: prorated
- No refund: after policy period

## Verification Checklist
- [ ] Cancellation authorized
- [ ] Order cancelled
- [ ] Refund processed
- [ ] Services terminated
- [ ] Client notified
- [ ] Documented
