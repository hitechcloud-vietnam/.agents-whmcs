# WHMCS Client Note Add Workflow

## Purpose
Step-by-step guide for adding notes to client accounts in WHMCS.

## Prerequisites
- Client account exists
- Note content prepared
- Note visibility defined
- Appropriate permissions

## Workflow Steps

### Step 1: Note Creation
- Prepare note content
- Determine note type
- Identify related records
- Draft note text

### Step 2: Note Visibility
- Set note visibility:
  - Private (admin only)
  - Shared (staff visible)
  - Public (client visible)
- Configure visibility settings

### Step 3: Note Category
- Select note category:
  - General
  - Billing
  - Technical
  - Sales
  - Support
  - Compliance
- Apply category tag

### Step 4: Related Record Linking
- Link to client account
- Link to services (if applicable)
- Link to orders (if applicable)
- Link to tickets (if applicable)

### Step 5: Note Entry
- Add note to client
- Apply formatting
- Add attachments (if needed)
- Set priority level

### Step 6: Staff Notification
- Notify relevant staff
- Set reminder if needed
- Configure follow-up
- Assign action items

### Step 7: Client Visibility Check
- If public note: notify client
- If private: maintain confidentiality
- Configure notification rules
- Update client portal

### Step 8: Search Optimization
- Add searchable tags
- Include keywords
- Add reference numbers
- Improve findability

### Step 9: Note Review
- Review note content
- Verify accuracy
- Check for errors
- Confirm completeness

### Step 10: Documentation
- Log note addition
- Record author
- Document timestamp
- Update audit trail

## Note Types
- General: miscellaneous information
- Billing: payment, invoice notes
- Technical: server, configuration notes
- Sales: sales activity, proposals
- Support: support interaction notes
- Compliance: verification, audit notes

## Note Best Practices
- Be concise and clear
- Use consistent formatting
- Include dates and references
- Tag for easy search

## Verification Checklist
- [ ] Note created
- [ ] Visibility set
- [ ] Links added
- [ ] Notifications sent
- [ ] Documented
