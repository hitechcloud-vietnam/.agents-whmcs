# WHMCS License Management Workflow

## Purpose
Step-by-step guide for managing WHMCS license.

## Prerequisites
- WHMCS admin access
- License key available
- License renewal plan

## Step 1: Access License Settings
- Navigate to Configuration > License
- View license status
- Check expiration date

## Step 2: Verify License Status
- Check active/expired status
- View license type
- Check registered domain
- Verify addon licenses

## Step 3: Update License Key
To update license:
- Enter new license key
- Click "Update License"
- Verify activation
- Check new status

## Step 4: Addon Licenses
Manage addon licenses:
- SLA license
- Addon modules
- Additional services
- Premium support

## Step 5: License Renewal
- Check renewal pricing
- Process renewal
- Update license key
- Verify extended date

## Step 6: Transfer License
For server change:
- Deactivate on old server
- Get transfer key
- Activate on new server
- Verify transfer

## Step 7: License Troubleshooting
- Clear license cache
- Re-validate license
- Check domain match
- Contact support if needed

## License Issues
- Expired license
- Domain mismatch
- Invalid key
- Server mismatch
