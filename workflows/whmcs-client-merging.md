# WHMCS Client Merging Workflow

## Purpose
Step-by-step guide for merging client accounts in WHMCS.

## Prerequisites
- Two or more client accounts
- Merge authorization
- Duplicate verification
- Data consolidation plan

## Workflow Steps

### Step 1: Merge Request Received
- Receive merge request
- Identify accounts to merge
- Document merge reason
- Verify authorization

### Step 2: Account Identification
- Identify primary account (keep)
- Identify secondary account(s) (merge)
- Verify ownership
- Document all accounts

### Step 3: Duplicate Verification
- Confirm duplicate accounts
- Verify same client
- Check for conflicts
- Review merge eligibility

### Step 4: Data Review
- Review data in each account
- Identify data to merge
- Check for conflicts
- Plan data consolidation

### Step 5: Service Handling
- Review services in each account
- Plan service migration
- Check for service conflicts
- Document migration plan

### Step 6: Financial Review
- Check balances in each account
- Consolidate credits
- Transfer invoices
- Handle outstanding payments

### Step 7: Approval Process
- Obtain merge approval
- Document merge plan
- Set merge conditions
- Schedule merge date

### Step 8: Merge Execution
- Transfer services to primary
- Move billing information
- Consolidate notes
- Merge contacts

### Step 9: Account Cleanup
- Archive merged accounts
- Update references
- Clean up duplicates
- Update reporting

### Step 10: Notification and Documentation
- Notify client of merge
- Provide merge summary
- Log merge details
- Update audit trail

## Merge Considerations
- Primary account selection
- Service compatibility
- Billing consolidation
- Data conflicts
- Historical records

## Verification Checklist
- [ ] Duplicates verified
- [ ] Data reviewed
- [ ] Approval obtained
- [ ] Merge executed
- [ ] Client notified
- [ ] Documented
