# WHMCS Order Review Workflow

## Purpose
Step-by-step guide for reviewing orders in WHMCS.

## Prerequisites
- Order received
- Admin access
- Review criteria defined
- Approval workflow configured

## Workflow Steps

### Step 1: Order Receipt
- Identify new order
- Review order details
- Check order status
- Document review start

### Step 2: Customer Verification
- Verify customer identity
- Check account history
- Review verification status
- Assess risk level

### Step 3: Product Verification
- Verify products ordered
- Check product availability
- Review configuration
- Validate pricing

### Step 4: Payment Review
- Check payment status
- Verify payment method
- Review transaction details
- Check for fraud indicators

### Step 5: Address Verification
- Verify billing address
- Verify service address
- Check for discrepancies
- Validate address format

### Step 6: Risk Assessment
- Run fraud checks
- Review risk score
- Check for red flags
- Evaluate risk level

### Step 7: Compliance Check
- Verify terms acceptance
- Check for policy violations
- Review restricted products
- Validate requirements

### Step 8: Documentation
- Document review findings
- Record risk assessment
- Note any concerns
- Update order notes

### Step 9: Decision Making
- Approve order
- Flag for manual review
- Request additional info
- Reject order

### Step 10: Next Steps
- Execute decision
- Update order status
- Notify customer
- Document outcome

## Review Criteria
- Payment verification
- Customer legitimacy
- Product availability
- Risk assessment
- Compliance check

## Verification Checklist
- [ ] Customer verified
- [ ] Payment checked
- [ ] Risk assessed
- [ ] Decision made
- [ ] Documented
