# WHMCS Report Forecast Workflow

## Purpose
Predict future metrics and trends for planning.

## Forecasting Access

### Navigation
1. Navigate to: Reports > Forecast
2. Select metric
3. Configure parameters

### Available Forecasts
```
Metrics:
- Revenue forecast
- Order forecast
- Client forecast
- Capacity forecast
```
