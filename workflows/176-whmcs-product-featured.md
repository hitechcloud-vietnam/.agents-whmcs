# WHMCS Featured Product Workflow

## Purpose
Step-by-step guide for marking products as featured.

## Prerequisites
- WHMCS admin access
- Products configured
- Featured strategy defined

## Step 1: Access Featured Settings
- Navigate to Catalog > Products/Services
- Select product
- Find "Featured" or "Highlighted" option

## Step 2: Set Featured Status
- Enable "Featured Product"
- Or set "Show in Featured Section"
- Configure featured display order
- Set featured badge

## Step 3: Configure Display
- Set featured product order
- Choose featured products list
- Configure featured section position
- Set featured product layout

## Step 4: Featured Product Marketing
- Create featured banner
- Set featured product price
- Configure featured call-to-action
- Set featured period

## Step 5: Test Featured Display
- View order form
- Verify featured section
- Check featured badge
- Test featured ordering

## Step 6: Rotate Featured Products
- Schedule featured changes
- Set featured rotation
- Configure auto-rotation
- Set featured dates

## Featured Product Benefits
- Increased visibility
- Higher conversion
- Clear call-to-action
- Marketing opportunity
