# WHMCS Report Export Workflow

## Purpose
Export and share WHMCS reports in various formats.

## Export Options

### Access Export
1. Navigate to any report
2. Click "Export" button
3. Choose format

### Available Formats
```
- CSV (Comma Separated)
- Excel (.xlsx)
- PDF
- Print
```

## CSV Export

### Configuration
```
Options:
- Delimiter: comma, semicolon, tab
- Encoding: UTF-8, UTF-16
- Include headers: Yes/No
```

### Best For
```
Use CSV when:
- Importing to spreadsheets
- Data analysis
- Large datasets
- Custom processing
```

## Excel Export

### Configuration
