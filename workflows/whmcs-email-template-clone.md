# WHMCS Email Template Clone Workflow

## Purpose
Duplicate an existing email template to create variations for different purposes.

## Prerequisites
- WHMCS admin access
- Existing template to clone

## Steps

### Step 1: Select Template to Clone
1. Navigate to: Configuration > System > Email Templates
2. Find the template you want to duplicate
3. Click the "Clone" icon (or dropdown > Clone)

### Step 2: Configure New Template
1. **Name**: Enter new template name
2. **Unique ID**: Auto-generated, can customize
3. All other settings copied from original

### Step 3: Modify as Needed
1. Change subject line
2. Update content for new purpose
3. Adjust conditions/triggers
4. Update styling if needed

### Step 4: Save Cloned Template
1. Click "Save Changes"
2. Test the new template

## Use Cases
- Create localized versions
- Make product-specific variations
- Develop A/B testing versions
- Branch for different client groups
