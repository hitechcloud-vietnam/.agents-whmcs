# WHMCS Service Report Workflow

## Purpose
Generate and analyze service/product reports.

## Service Report Access

### Navigation
1. Navigate to: Reports > Services
2. Select report type
3. Set parameters

### Report Types
```
Available:
- Service Summary
- Product Performance
- Service Status
- Renewal Report
- Cancellation Report
```

## Service Summary

### Overview
```
Metrics:
- Total Services
- Active Services
- Suspended Services
- Terminated Services
```

### Distribution
```
By:
- Product type
- Billing cycle
- Status
- Client group
```

## Product Performance

### Sales Analysis
```
Shows:
- Units sold by product
- Revenue by product
- Average price
- Discounts given
```

### Performance Ranking
```
Rank by:
- Revenue
- Units sold
- Margin
- Growth
```

### Status Breakdown
