# WHMCS Sales Report Workflow

## Purpose
Generate and analyze sales reports in WHMCS.

## Sales Report Access

### Navigation
1. Navigate to: Reports > Sales
2. Select report type
3. Set parameters

### Report Types
```
Available:
- Sales Summary
- Sales by Product
- Sales by Order
- Sales by Client
- Sales Trends
```

## Sales Summary

### Overview
```
Displays:
- Total Orders
- Total Sales
- Average Order Value
- Orders Today/This Week/This Month
```

### Metrics
```
Comparison:
- vs Last Period
- vs Last Year
- Growth Rate
```
