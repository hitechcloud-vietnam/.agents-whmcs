# WHMCS Client Closure Workflow

## Purpose
Step-by-step guide for closing client accounts in WHMCS.

## Prerequisites
- Client account exists
- Closure request received
- Authorization verified
- Outstanding issues resolved

## Workflow Steps

### Step 1: Closure Request Received
- Receive closure request
- Verify client identity
- Document closure reason
- Collect authorization

### Step 2: Account Review
- Review account status
- List all services
- Check outstanding balances
- Identify pending orders

### Step 3: Outstanding Items Resolution
- Collect final payments
- Cancel pending orders
- Settle invoices
- Clear credits/debits

### Step 4: Service Cancellation
- Cancel all active services
- Follow cancellation workflow
- Process final billing
- Handle refunds

### Step 5: Data Assessment
- Evaluate data retention requirements
- Check legal hold issues
- Review retention policy
- Plan data handling

### Step 6: Client Notification
- Send closure confirmation
- Detail account closure
- Explain data retention
- Provide final invoices

### Step 7: Access Termination
- Disable all access
- Revoke permissions
- Close API access
- Deactivate integrations

### Step 8: Data Handling
- Retain data per policy
- Prepare data export
- Schedule deletion
- Document retention

### Step 9: Financial Settlement
- Process final refunds
- Apply credits
- Generate final statement
- Close billing account

### Step 10: Documentation
- Log closure details
- Record closure reason
- Document data handling
- Archive account

## Closure Reasons
- Customer requested
- Non-renewal
- Policy violation
- Fraud/Abuse
- Bankruptcy
- Business closure

## Data Retention Policy
- Billing records: 7 years
- Personal data: per GDPR
- Service data: 30-90 days
- Communications: 3 years

## Verification Checklist
- [ ] All items resolved
- [ ] Services cancelled
- [ ] Payments settled
- [ ] Access terminated
- [ ] Client notified
- [ ] Documented
