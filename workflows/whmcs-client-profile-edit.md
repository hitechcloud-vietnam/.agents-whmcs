# WHMCS Client Profile Edit Workflow

## Purpose
Step-by-step guide for editing client profiles in WHMCS.

## Prerequisites
- Client account exists
- Edit access verified
- Changes identified
- Required permissions

## Workflow Steps

### Step 1: Profile Access
- Navigate to client profile
- Identify profile section
- Verify edit permissions
- Document current values

### Step 2: Change Identification
- Determine field(s) to edit
- Collect new values
- Verify change authority
- Document changes

### Step 3: Field-Level Edit

### Personal Information
- First name, Last name
- Company name
- Email address
- Date of birth

### Contact Information
- Phone number
- Address details
- City, State, Country
- Postal code

### Account Settings
- Language preference
- Currency
- Tax exempt status
- Client group

### Step 4: Validation
- Validate email format
- Check phone number format
- Verify address validity
- Ensure required fields

### Step 5: Duplicate Check
- Check for duplicate email
- Verify no conflicts
- Check for similar accounts
- Flag if issues found

### Step 6: Save Changes
- Apply profile changes
- Update database
- Preserve history
- Log changes

### Step 7: Notification
- Notify client of changes (if critical)
- Send confirmation email
- Update audit log
- Document change reason

### Step 8: Related Records Update
- Update associated orders
- Update service records
- Update invoice contacts
- Sync billing info

### Step 9: Verification
- Confirm changes saved
- Verify data accuracy
- Test login (if email changed)
- Check billing impact

### Step 10: Documentation
- Log all changes
- Record change reason
- Document authority
- Update client notes

## Common Edit Scenarios
- Name correction
- Address update
- Email change
- Phone update
- Company name change

## Verification Checklist
- [ ] Changes validated
- [ ] Save confirmed
- [ ] Notifications sent
- [ ] Related records updated
- [ ] Documented
