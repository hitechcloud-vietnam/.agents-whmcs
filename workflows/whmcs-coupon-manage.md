# WHMCS Coupon Manage Workflow

## Purpose
Manage existing coupon codes and their settings.

## Coupon Management Overview

### Access Coupons
1. Navigate to: Configuration > Promotions
2. View all coupons
3. Filter/sort as needed

## View Coupon Details

### Information Display
```
Shows:
- Coupon name and code
- Discount type and value
- Usage statistics
- Validity period
- Conditions applied
```

## Managing Coupon Settings

### Edit Coupon
```
Steps:
1. Click on coupon
2. Modify settings
3. Save changes
```

### Adjust Limits
```
Modify:
- Maximum uses
- Uses per client
- Minimum order value
```

### Update Conditions
```
Change:
- Products included
- Client groups
- Exclusions
```

## Coupon Status

### Active
- Available for use
- Visible to clients
- Validates normally

### Inactive
- Temporarily disabled
- Shows "invalid" to clients
- Can be reactivated

### Expired
- Past end date
- Automatically disabled
- Keep for records

## Usage Management

### View Usage
```
Track:
- Total uses
- Remaining uses
- By client
- By date
```

### Reset Usage
```
Options:
- Reset total uses
- Reset per-client uses
- Extend expiration
```

### Block Usage
```
Prevent:
- Single client use
- Multiple uses
- Specific products
```

### Archive Old
```
Archive:
- Expired coupons
- Never-used coupons
- Replaced coupons

Keep records for:
- Tax/reporting

```

```
- Only after archiving

- Cannot be undone

```
