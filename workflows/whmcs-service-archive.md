# WHMCS Service Archive Workflow

## Purpose
Step-by-step guide for archiving services in WHMCS.

## Prerequisites
- Admin access
- Archive policy defined
- Retention requirements set
- Data backup completed

## Workflow Steps

### Step 1: Archive Identification
- Identify services to archive
- Review archive criteria
- Check eligibility
- Apply filters

### Step 2: Archive Policy Review
- Check retention requirements
- Verify compliance needs
- Review legal requirements
- Confirm data handling

### Step 3: Data Assessment
- Evaluate data size
- Check attachment count
- Review transaction history
- Assess dependencies

### Step 4: Pre-Archive Backup
- Create data backup
- Export complete service record
- Archive related documents
- Store safely

### Step 5: Archive Preparation
- Clear pending transactions
- Settle outstanding balances
- Close related tickets
- Document final state

### Step 6: Archive Execution
- Change service status
- Move to archive storage
- Update database status
- Remove from active lists

### Step 7: Relationship Handling
- Update related records
- Reassign dependencies
- Transfer ownership records
- Clear associations

### Step 8: Search Index Update
- Remove from active search
- Add to archive index
- Update search functionality
- Configure archive access

### Step 9: Verification
- Confirm archive complete
- Verify data integrity
- Test archive retrieval
- Validate access controls

### Step 10: Documentation
- Log archive details
- Document archive date
- Record retention period
- Update audit trail

## Archive Criteria
- Cancelled services (6+ months)
- Completed term
- No pending issues
- Financial records complete
- Legal requirements met

## Archive vs Delete
- Archive: Data preserved, searchable
- Delete: Data removed, not recoverable

## Verification Checklist
- [ ] Services identified
- [ ] Backup created
- [ ] Data prepared
- [ ] Archive executed
- [ ] Verification passed
- [ ] Documented
