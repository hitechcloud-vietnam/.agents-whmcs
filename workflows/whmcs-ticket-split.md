# WHMCS Ticket Split Workflow

## Purpose
Step-by-step guide for splitting support tickets in WHMCS.

## Prerequisites
- Ticket with multiple issues
- Split reason identified
- Authorization verified
- Staff permissions

## Workflow Steps

### Step 1: Split Identification
- Identify multiple issues
- Review ticket content
- Determine split points
- Document split plan

### Step 2: Issue Analysis
- Analyze each issue
- Assess complexity
- Identify responsible departments
- Plan new tickets

### Step 3: Content Separation
- Extract content for each issue
- Organize by topic
- Remove unrelated content
- Preserve context

### Step 4: New Ticket Creation
- Create new tickets
- Set appropriate subjects
- Assign to departments
- Configure priorities

### Step 5: Attachment Handling
- Split attachments
- Link to relevant tickets
- Update references
- Verify accessibility

### Step 6: Thread Management
- Move replies to appropriate
- Preserve conversation flow
- Update timestamps
- Maintain context

### Step 7: Original Ticket Update
- Remove split content
- Add split notification
- Update original ticket
- Link to new tickets

### Step 8: Assignment
- Assign new tickets
- Route to appropriate staff
- Configure follow-ups
- Set reminders

### Step 9: Client Notification
- Notify client
- Explain split
- Provide new ticket numbers
- Confirm separation

### Step 10: Documentation
- Log split details
- Record split reasons
- Document new tickets
- Update audit trail

## Split Scenarios
- Multiple unrelated issues
- Different departments needed
- Complex issue requiring specialist
- Thread topic change

## Verification Checklist
- [ ] Issues identified
- [ ] Tickets created
- [ ] Content split
- [ ] Client notified
- [ ] Documented
