# WHMCS Promotion Analytics Workflow

## Purpose
Track and analyze promotional campaign performance.

## Key Metrics

### Usage Metrics
```
- Total uses
- Unique clients
- Uses per day
- Peak usage time
```

### Financial Metrics
```
- Revenue generated
- Revenue per use
- Discount amount given
- Profit margin impact
```

### Conversion Metrics
```
- Conversion rate
- New vs returning
- Upsell revenue
- Repeat usage
```

## Analytics Setup

### Step 1: Enable Tracking
1. Navigate to: Configuration > Promotions
2. Enable "Track Usage"
3. Set retention period

### Step 2: Configure Events
```
Track:
- Promotion displayed
- Promotion applied
- Order completed
- Promotion rejected
```

## Viewing Analytics

### Dashboard
```
Access:
- Reports > Promotion Performance
- View by date range
- Filter by promotion
- Compare promotions
```

### Reports Available
```
- Promotion usage over time
- Revenue by promotion
- Client participation
- Conversion funnel
```


### Trend Analysis
```
Compare:
- This month vs last month
- This year vs last year
- By channel
- By segment
```

## ROI Calculation

### Formula
```
ROI = (Revenue - Promotion Cost) / Promotion Cost

Example:
- Revenue generated: $10,000
- Cost of discount: $2,000
- ROI: 400% (4x return)
```

### Attribution
```
Track:
- Direct revenue from promotion
- Customer lifetime value
- Repeat purchases
- Cross-sell revenue
```
