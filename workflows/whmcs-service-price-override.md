# WHMCS Service Price Override Workflow

## Purpose
Step-by-step guide for applying custom pricing to services in WHMCS.

## Prerequisites
- Active service
- Admin access required
- Override authorization
- Documentation required

## Workflow Steps

### Step 1: Override Request
- Receive price override request
- Identify service affected
- Document current pricing
- Capture target price

### Step 2: Authorization Check
- Verify admin permission
- Check override policy
- Document approval authority
- Record authorization

### Step 3: Reason Documentation
- Record override reason
- Categorize override type
- Set effective dates
- Document terms

### Step 4: Pricing Calculation
- Apply custom price
- Calculate savings
- Determine end date
- Project revenue impact

### Step 5: System Configuration
- Apply price override in WHMCS
- Set override expiration
- Configure billing behavior
- Enable override flags

### Step 6: Invoice Adjustment
- Adjust next invoice
- Apply custom pricing
- Document adjustments
- Update billing schedule

### Step 7: Client Communication
- Notify client of price change
- Explain override terms
- Detail effective period
- Highlight savings

### Step 8: Monitoring Setup
- Set expiration reminder
- Create follow-up task
- Monitor override status
- Track revenue impact

### Step 9: Verification
- Confirm price applied
- Verify invoice amounts
- Test billing cycle
- Ensure override active

### Step 10: Documentation
- Log full override details
- Record authorization
- Document reason and terms
- Update service record

## Override Types
- Temporary discount
- Loyalty pricing
- Competitor match
- Special arrangement
- Error correction

## Verification Checklist
- [ ] Override authorized
- [ ] Price applied correctly
- [ ] Client notified
- [ ] Expiration set
- [ ] Documentation complete
