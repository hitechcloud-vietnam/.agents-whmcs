# WHMCS Order Notes Workflow

## Purpose
Step-by-step guide for managing order notes in WHMCS.

## Prerequisites
- Order exists
- Note content prepared
- Note visibility defined
- Appropriate permissions

## Workflow Steps

### Step 1: Note Creation
- Prepare note content
- Determine note type
- Identify related records
- Draft note text

### Step 2: Note Visibility
- Set note visibility:
  - Internal only
  - Staff visible
  - Client visible
- Configure visibility settings

### Step 3: Note Category
- Select note category:
  - General
  - Billing
  - Technical
  - Admin
  - Compliance
- Apply category tag

### Step 4: Related Record Linking
- Link to order
- Link to client (if applicable)
- Link to services (if applicable)
- Link to tickets (if applicable)

### Step 5: Note Entry
- Add note to order
- Apply formatting
- Add attachments (if needed)
- Set priority level

### Step 6: Notification
- Notify relevant staff
- Set reminder if needed
- Configure follow-up
- Assign action items

### Step 7: Client Visibility
- If public: notify client
- If private: maintain confidentiality
- Configure notification rules
- Update client portal (if applicable)

### Step 8: Note Search
- Add searchable tags
- Include keywords
- Add reference numbers
- Improve findability

### Step 9: Note Review
- Review note content
- Verify accuracy
- Check for errors
- Confirm completeness

### Step 10: Documentation
- Log note addition
- Record author
- Document timestamp
- Update audit trail

## Note Types
- General notes
- Billing notes
- Technical notes
- Admin notes
- Compliance notes

## Note Best Practices
- Be concise and clear
- Use consistent formatting
- Include dates and references
- Tag for easy search

## Verification Checklist
- [ ] Note created
- [ ] Visibility set
- [ ] Links added
- [ ] Notifications sent
- [ ] Documented
