# WHMCS Order Merge Workflow

## Purpose
Step-by-step guide for merging orders in WHMCS.

## Prerequisites
- Multiple orders identified
- Merge reason identified
- Same client account
- Authorization verified

## Workflow Steps

### Step 1: Merge Request
- Receive merge request
- Identify orders to merge
- Verify same client
- Document merge reason

### Step 2: Order Analysis
- Review all orders
- Check order statuses
- Assess merge eligibility
- Identify conflicts

### Step 3: Item Consolidation
- List all items
- Identify duplicates
- Plan consolidation
- Determine final items

### Step 4: Pricing Review
- Calculate combined pricing
- Review applicable discounts
- Adjust for merged order
- Verify totals

### Step 5: Financial Review
- Check payments on each
- Plan payment handling
- Calculate credits
- Determine balance

### Step 6: Approval Process
- Obtain approval
- Document merge plan
- Set merge conditions
- Verify authorization

### Step 7: New Order Creation
- Create consolidated order
- Add all items
- Set appropriate status
- Link to original orders

### Step 8: Invoice Handling
- Create new invoice
- Apply payments
- Handle credits
- Void original invoices

### Step 9: Service Handling
- Consolidate services
- Update service links
- Manage service overlap
- Update billing

### Step 10: Documentation
- Log merge details
- Record item consolidation
- Document financial changes
- Update audit trail

## Merge Scenarios
- Multiple orders by same client
- Duplicate orders
- Split order consolidation
- Pricing corrections

## Verification Checklist
- [ ] Orders reviewed
- [ ] Items consolidated
- [ ] Invoices handled
- [ ] Services updated
- [ ] Documented
