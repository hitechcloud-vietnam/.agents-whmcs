# WHMCS Report Comparison Workflow

## Purpose
Compare metrics across different periods, products, or segments.

## Comparison Access

### Navigation
1. Navigate to: Reports > Comparison
2. Select comparison type
3. Set parameters

### Comparison Types
```
Available:
- Period comparison
- Product comparison
- Client comparison
- Channel comparison
```

## Period Comparison

### Time Ranges
```
Compare:
- This month vs last month
- This quarter vs last quarter
- This year vs last year
- Custom date ranges
```

### Metrics Compared
```
Show:
- Revenue
- Orders
- Clients
- Average values
```
