# WHMCS Service Change Cycle Workflow

## Purpose
Step-by-step guide for changing service billing cycles in WHMCS.

## Prerequisites
- Active service
- Multiple billing cycles available
- Client request
- Payment verification

## Workflow Steps

### Step 1: Request Received
- Client requests cycle change
- Identify current billing cycle
- Determine target cycle
- Document request details

### Step 2: Policy Review
- Check cycle change policy
- Verify no restrictions
- Review any fees
- Confirm availability

### Step 3: Pricing Calculation
- Calculate pricing for new cycle
- Compare current vs new rates
- Apply any cycle discounts
- Generate adjustment invoice

### Step 4: Prorate Calculation
- Calculate credit for remaining time
- Apply to new cycle pricing
- Generate prorate invoice
- Document calculation

### Step 5: Payment Processing
- Process any prorate payment
- Update payment method
- Verify successful payment
- Record transaction

### Step 6: Cycle Update
- Change billing cycle setting
- Update next due date
- Adjust term calculations
- Configure new schedule

### Step 7: Invoice Schedule Update
- Adjust upcoming invoices
- Update recurring amounts
- Set new billing dates
- Configure auto-billing

### Step 8: Confirmation
- Send cycle change confirmation
- Detail new billing schedule
- Show pricing comparison
- Provide next billing date

### Step 9: Documentation
- Log cycle change
- Record pricing adjustments
- Document effective date
- Update service record

## Billing Cycle Options
- Monthly
- Quarterly
- Semi-annually
- Annually
- Biennially
- Triennially

## Common Discounts by Cycle
- Monthly: base price
- Quarterly: 2-5% discount
- Semi-annually: 5-10% discount
- Annually: 10-20% discount

## Verification Checklist
- [ ] Cycle change approved
- [ ] Payment processed
- [ ] Cycle updated
- [ ] Billing adjusted
- [ ] Client notified
- [ ] Documentation complete
