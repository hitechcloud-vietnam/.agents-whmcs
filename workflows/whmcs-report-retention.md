# WHMCS Report Retention Workflow

## Purpose
Analyze customer retention metrics and patterns.

## Retention Report Access

### Navigation
1. Navigate to: Reports > Retention
2. Select view
3. Set parameters

### Retention Types
```
Types:
- Customer retention
- Revenue retention
- Product retention
- Cohort retention
```

## Customer Retention

### Metrics
```
Calculate:
Retention Rate = Retained Customers / Total Customers x 100

Track:
- Monthly retention
- Quarterly retention
- Annual retention
```

### Cohorts
```
Analyze:
- Signup cohort retention
- Product cohort retention
- Segment cohort retention
```

## Revenue Retention

### Metrics
```
Calculate:
Net Revenue Retention = (MRR + Expansion - Contraction - Churned) / Starting MRR x 100

Track:
- Gross revenue retention
- Net revenue retention
- Expansion rate
- Churn rate
```

### Analysis
```
Shows:
- Revenue retained
- Expansion contribution
- Contraction impact
- Net change
```
