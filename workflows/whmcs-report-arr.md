# WHMCS Report ARR Workflow

## Purpose
Generate and analyze Annual Recurring Revenue reports.

## ARR Report Access

### Navigation
1. Navigate to: Reports > ARR
2. Select view
3. Set parameters

### ARR Components
```
ARR includes:
- Annual subscriptions
- Yearly contracts
- Multi-year commitments
- Annual add-ons
```

## ARR Calculation

### From MRR
```
Calculate:
ARR = MRR x 12

Example:
MRR = $10,000
ARR = $120,000
```

### From Contracts
```
Calculate:
ARR = Sum of all annual contract values

Include:
- Annual plans
- Multi-year contracts
- Annual add-ons
```
