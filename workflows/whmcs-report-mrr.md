# WHMCS Report MRR Workflow

## Purpose
Generate and analyze Monthly Recurring Revenue reports.

## MRR Report Access

### Navigation
1. Navigate to: Reports > MRR
2. Select view
3. Set parameters

### MRR Components
```
MRR includes:
- Recurring service revenue
- Recurring add-ons
- Monthly subscriptions
- Recurring fees
```

## MRR Movement

### Changes
```
Track:
- New MRR (new clients)
- Expansion MRR (upgrades)
- Contraction MRR (downgrades)
- Churned MRR (cancellations)
```

### Formula
```
Net MRR = New + Expansion - Contraction - Churned
```
