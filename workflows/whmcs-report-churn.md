# WHMCS Report Churn Workflow

## Purpose
Analyze customer and revenue churn metrics.

## Churn Report Access

### Navigation
1. Navigate to: Reports > Churn
2. Select view
3. Set parameters

### Churn Types
```
Types:
- Customer churn
- Revenue churn
- Service churn
- Voluntary vs Involuntary
```

## Customer Churn

### Metrics
```
Calculate:
Churn Rate = Churned Customers / Total Customers x 100

Track:
- Monthly churn rate
- Quarterly churn rate
- Annual churn rate
```

### Analysis
```
Shows:
- Churned customers
- Churn reasons
- Churn timing
- At-risk indicators
```

## Revenue Churn

### Metrics
```
Calculate:
Revenue Churn = Churned MRR / Total MRR x 100

Track:
- MRR churn rate
- ARR churn rate
- Gross vs Net churn
```

### Breakdown
```
Shows:
- Revenue lost
- Revenue from churned customers
- Revenue from downgrades
```
