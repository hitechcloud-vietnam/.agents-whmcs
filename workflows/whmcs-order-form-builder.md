# WHMCS Order Form Builder Workflow

## Purpose
Create and customize the order form using WHMCS's order form builder for optimized conversion and user experience.

## Prerequisites
- WHMCS installation with order form access
- Products and pricing configured
- Design/branding guidelines prepared

## Step-by-Step Process

### Step 1: Access Order Form Builder
1. Log into WHMCS admin
2. Navigate to `Configuration > Order Form > Order Form Builder`
3. View available templates

### Step 2: Select Starting Template
1. Choose from available templates:
   - Standard Layout
   - Product Slider
   - Category Grid
   - Minimal Design
   - Custom template
2. Preview template appearance
3. Select template as base

### Step 3: Add Order Form Components
1. Drag and drop components:
   - Product Groups
   - Individual Products
   - Configurable Options
   - Addon Modules
   - Domain Search
   - Cart Summary
   - Featured Products
   - Custom Content Blocks

### Step 4: Configure Product Display
1. Set product card settings:
   - Product name display
   - Description length
   - Feature highlighting
   - Price display format
   - Add to cart button style
2. Configure product grouping

### Step 5: Configure Domain Search
1. Set up domain search component:
   - TLD selection for search
   - Pricing display
   - Transfer options
   - Suggestion engine settings
2. Configure domain suggestions

### Step 6: Style Configuration
1. Customize appearance:
   - Color scheme
   - Typography settings
   - Spacing and layout
   - Button styles
   - Card styling
2. Set responsive breakpoints

### Step 7: Configure Cart Settings
1. Cart component settings:
   - Show/hide elements
   - Cross-sell display
   - Upsell placement
   - Checkout button styling
2. Set cart summary behavior

### Step 8: Add Custom Content
1. Insert custom content blocks:
   - HTML content areas
   - Feature comparison tables
   - Trust badges
   - Testimonials
   - FAQ sections
2. Position content strategically

### Step 9: Configure Checkout Flow
1. Set checkout integration:
   - Multi-page or single-page checkout
   - Step indicators
   - Progress tracking
2. Configure checkout options:
   - Domain selection step
   - Configuration step
   - Payment selection step
   - Review step

### Step 10: Test and Optimize
1. Preview order form in browser
2. Test complete purchase flow
3. Check mobile responsiveness
4. A/B test different configurations
5. Monitor conversion metrics

## Verification Checklist
- [ ] All products display correctly
- [ ] Add to cart functions work
- [ ] Domain search operational
- [ ] Checkout flow completes
- [ ] Mobile responsive
- [ ] Brand consistency verified
