# WHMCS Report Email Workflow

## Purpose
Configure email delivery for scheduled reports.

## Email Configuration

### Access
1. Navigate to: Reports > Scheduled
2. Select schedule
3. Configure email tab

### Settings
```
Configure:
- Recipients
- Subject
- Body
- Attachments
```

## Recipient Management

### Add Recipients
```
Options:
- Add email address
- Select from admin list
- Select from team
```

### Recipient Types
```
Types:
- Primary recipients
- CC recipients
- BCC recipients
```

### Dynamic Recipients
```
Options:
- By role
- By department
- By client group
```

## Email Content

### Subject Line
```
Options:
- Static text
- Dynamic with report name
- Date in subject
- Custom template
```

### Body Content
```
Options:
- Plain text
- HTML formatted
- Summary included
- Link to report
```

## Attachment Options

### Configure Attachments
```
Options:
- Attach report
- Link only (no attachment)
- Include charts
- Compress if large
```

### Multiple Attachments
```
Options:
- All formats
- Specific format
- Separate files
- Combined archive
```

## Email Templates

### Pre-built Templates
```
Use:
- Standard report
- Executive summary
- Detailed breakdown
```

### Custom Templates
```
Create:
- Header with logo
- Branded formatting
- Custom message
```

## Scheduling Email

### Delivery Time
```
Options:
- Immediately after generation
- Delayed delivery
- Specific time
```

### Frequency
```
Options:
- Every run
- Weekly summary
- Critical only
```

### Test Delivery
```
Options:

```

### Validation
```
Check:
```
