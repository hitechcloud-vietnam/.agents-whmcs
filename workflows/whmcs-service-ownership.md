# WHMCS Service Ownership Change Workflow

## Purpose
Step-by-step guide for changing service ownership in WHMCS.

## Prerequisites
- Active service
- Both parties consent
- Authorization documented
- Ownership change policy reviewed

## Workflow Steps

### Step 1: Ownership Change Request
- Receive ownership request
- Identify current owner
- Identify new owner
- Document transfer reason

### Step 2: Current Owner Consent
- Confirm current owner approval
- Collect authorization
- Verify owner identity
- Document consent

### Step 3: New Owner Identification
- Verify new owner exists
- If not, create account
- Verify identity
- Collect required info

### Step 4: Service Review
- Document current service details
- Check outstanding balances
- Review contract terms
- Identify transfer restrictions

### Step 5: Terms Acceptance
- New owner accepts terms
- Review transfer conditions
- Confirm liability transfer
- Document agreement

### Step 6: Financial Settlement
- Clear outstanding invoices
- Transfer billing responsibility
- Apply any credits
- Record transactions

### Step 7: Ownership Update
- Change service owner
- Update WHMCS records
- Transfer billing association
- Update account records

### Step 8: Server Update
- Change account ownership
- Update billing info
- Configure new owner access
- Remove old owner access

### Step 9: Notification
- Notify current owner
- Notify new owner
- Provide access details
- Confirm change complete

### Step 10: Documentation
- Log full ownership change
- Record all authorizations
- Document financial settlement
- Update all records

## Ownership Change Types
- Full transfer to new client
- Internal company transfer
- Corporate restructure
- Estate/inheritance transfer

## Verification Checklist
- [ ] Authorization confirmed
- [ ] Both parties verified
- [ ] Financials settled
- [ ] Ownership changed
- [ ] Server updated
- [ ] Both notified
- [ ] Documented
