# WHMCS Ticket Merge Reply Workflow

## Purpose
Step-by-step guide for handling merge replies in WHMCS.

## Prerequisites
- Tickets merged
- Reply received
- Correct ticket identification
- Staff permissions

## Workflow Steps

### Step 1: Reply Detection
- Identify merged ticket reply
- Detect reply to archived ticket
- Identify client response
- Route to correct ticket

### Step 2: Ticket Identification
- Locate active ticket
- Verify ticket relationship
- Check merge history
- Confirm correct ticket

### Step 3: Content Transfer
- Move reply content
- Preserve original message
- Update timestamps
- Add to active ticket

### Step 4: Client Notification
- Notify client
- Explain reply placement
- Provide active ticket number
- Confirm receipt

### Step 5: Thread Update
- Update reply thread
- Add to conversation
- Maintain chronology
- Update status

### Step 6: Internal Documentation
- Log merge reply handling
- Document process
- Track issues
- Update audit trail

## Verification Checklist
- [ ] Reply identified
- [ ] Ticket confirmed
- [ ] Content transferred
- [ ] Client notified
- [ ] Documented
