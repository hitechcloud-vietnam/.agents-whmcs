# WHMCS Affiliate Recruitment Workflow

## Purpose
Recruit and onboard new affiliates for the affiliate program.

## Recruitment Strategies

### In-App Recruitment
```
Methods:
- Enable in client area
- Email existing clients
- Post-purchase upsell
- Dashboard notification
```

### Email Marketing
```
Target:
- Active clients
- High-value customers
- Social media followers
- Newsletter subscribers
```

### Landing Pages
```
Create:
- Dedicated affiliate page
- Benefits showcase
- Easy signup form
- Testimonials
```

## Affiliate Application

### Signup Process
1. Visit affiliate page
2. Register account (or existing client)
3. Agree to terms
4. Submit application

### Application Review
```
Steps:
1. Review application
2. Check qualifications
3. Approve/reject
4. Send welcome email
```

### Auto-Approval
```
Enable for:
- All signups
- Specific criteria
- Certain client groups
```

## Partner Programs

### Tiered Recruitment
```
Levels:
- Basic affiliates
- Partner affiliates
- VIP partners
```

### Benefits by Level
```
Example:
Basic: 10% commission
Partner: 15% commission + priority support
VIP: 20% commission + exclusive offers
```

## Recruitment Campaigns

### Campaign Types
```
- Limited time: Increased commission
- Referral contest
- Bonus for milestones
```

### Contest Structure
```
Example:
- Most referrals in month
- Prizes for top performers
- Bonus commission
```

### Metrics
