# WHMCS Order Refund Workflow

## Purpose
Step-by-step guide for processing order refunds in WHMCS.

## Prerequisites
- Original payment received
- Refund request received
- Refund reason documented
- Authorization verified

## Workflow Steps

### Step 1: Refund Request
- Receive refund request
- Identify original order
- Verify requestor identity
- Document refund reason

### Step 2: Original Transaction Review
- Locate original payment
- Verify payment status
- Check payment method
- Assess refund eligibility

### Step 3: Refund Eligibility
- Check refund policy
- Verify timeframe
- Review terms of service
- Assess refund validity

### Step 4: Amount Calculation
- Calculate refund amount
- Apply deductions
- Consider fees
- Determine net refund

### Step 5: Financial Review
- Review account balance
- Check credit status
- Assess refund impact
- Plan refund method

### Step 6: Approval Process
- Route for approval
- Verify authorization
- Document approval
- Set refund conditions

### Step 7: Refund Execution
- Process refund to original payment
- Or apply to account credit
- Process partial refunds
- Handle split refunds

### Step 8: Payment Gateway Update
- Update gateway records
- Request refund from gateway
- Verify refund processed
- Handle gateway errors

### Step 9: Order Update
- Update order status
- Record refund in WHMCS
- Update invoice
- Log transaction

### Step 10: Notification
- Send refund confirmation
- Detail refund amount
- Explain refund method
- Provide timeline

## Refund Methods
- Original payment method
- Account credit
- Store credit
- Exchange

## Verification Checklist
- [ ] Refund eligible
- [ ] Amount calculated
- [ ] Approved
- [ ] Refund processed
- [ ] Order updated
- [ ] Client notified
