# WHMCS Manual Order Workflow

## Purpose
Step-by-step guide for creating manual orders in WHMCS.

## Prerequisites
- Admin access
- Client account exists
- Products available
- Authorization verified

## Workflow Steps

### Step 1: Request Intake
- Receive manual order request
- Identify client
- Document order details
- Verify authorization

### Step 2: Client Verification
- Locate or create client
- Verify client details
- Check account status
- Review client history

### Step 3: Product Selection
- Identify products
- Document configurations
- Set billing cycle
- Calculate pricing

### Step 4: Pricing Review
- Apply manual pricing
- Apply discounts
- Calculate totals
- Document pricing

### Step 5: Order Creation
- Create order manually
- Set appropriate status
- Add order items
- Configure billing

### Step 6: Invoice Generation
- Generate invoice
- Apply pricing
- Set due date
- Send to client

### Step 7: Payment Processing
- Process payment manually
- Record payment
- Update invoice
- Update order status

### Step 8: Provisioning
- Provision services
- Activate services
- Configure settings
- Generate credentials

### Step 9: Documentation
- Document order reason
- Record authorization
- Note pricing decisions
- Update audit trail

### Step 10: Confirmation
- Send order confirmation
- Provide details
- Document next steps
- Update client

## Manual Order Reasons
- Phone orders
- Pricing adjustments
- Compensation orders
- Migration orders
- Legacy system imports

## Verification Checklist
- [ ] Client verified
- [ ] Order created
- [ ] Invoice generated
- [ ] Payment processed
- [ ] Provisioned
- [ ] Documented
