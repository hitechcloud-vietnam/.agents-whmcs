# WHMCS Order Split Workflow

## Purpose
Step-by-step guide for splitting orders in WHMCS.

## Prerequisites
- Multi-item order
- Split reason identified
- Authorization verified
- Inventory available

## Workflow Steps

### Step 1: Split Request
- Receive split request
- Identify original order
- Document split reason
- Verify authorization

### Step 2: Order Analysis
- Review order contents
- Identify split points
- Assess items to separate
- Determine split method

### Step 3: Inventory Check
- Verify item availability
- Check product status
- Assess fulfillment capability
- Plan split items

### Step 4: Order Split Planning
- Define new order structure
- Calculate pricing for each
- Plan billing distribution
- Document split plan

### Step 5: New Order Creation
- Create new order(s)
- Move selected items
- Set appropriate status
- Link to original order

### Step 6: Invoice Handling
- Split original invoice
- Create new invoices
- Update billing records
- Handle payments

### Step 7: Payment Reallocation
- Reallocate payments
- Update invoice statuses
- Handle over/under payment
- Reconcile finances

### Step 8: Fulfillment Planning
- Plan fulfillment for each
- Assign fulfillment order
- Configure provisioning
- Set priorities

### Step 9: Fulfillment Execution
- Execute fulfillments
- Process each order
- Track progress
- Handle issues

### Step 10: Documentation
- Log split details
- Record item distribution
- Document financial changes
- Update audit trail

## Split Scenarios
- Partial fulfillment
- Payment issues
- Product substitution
- Customer request
- Pricing adjustment

## Verification Checklist
- [ ] Split planned
- [ ] Orders created
- [ ] Invoices split
- [ ] Payments handled
- [ ] Fulfillment complete
- [ ] Documented
