# WHMCS Service Sort Workflow

## Purpose
Step-by-step guide for sorting service lists in WHMCS.

## Prerequisites
- WHMCS access
- Services loaded
- Sort objective defined

## Workflow Steps

### Step 1: Sort Objective
- Define sorting purpose
- Identify primary sort field
- Determine secondary sort
- Set sort direction

### Step 2: Sort Field Selection

### Common Sort Fields
- Service ID
- Client name
- Product name
- Next due date
- Registration date
- Amount
- Status

### Sort Directions
- Ascending (A-Z, 1-9)
- Descending (Z-A, 9-1)

### Step 3: Sort Application
- Apply primary sort
- Apply secondary sort (if needed)
- Set sort direction
- Execute sort

### Step 4: Sort Verification
- Verify sort order
- Check for errors
- Validate results
- Confirm intended order

### Step 5: Results Management
- Review sorted results
- Identify patterns
- Extract needed data
- Prepare for action

## Multi-Level Sorting
- Primary sort: Status
- Secondary sort: Due date
- Tertiary sort: Client name

## Common Sort Use Cases
- Revenue ranking
- Expiration tracking
- Client listing
- Status grouping
- Date ordering

## Verification Checklist
- [ ] Sort applied correctly
- [ ] Results verified
- [ ] Data extracted
