# WHMCS Service Upgrade Request Workflow

## Purpose
Step-by-step guide for processing client upgrade requests in WHMCS.

## Prerequisites
- Active service
- Upgrade path available
- Client authenticated
- Payment method configured

## Workflow Steps

### Step 1: Request Intake
- Client submits upgrade request
- Identify current service
- Capture target upgrade
- Document special requirements

### Step 2: Current Service Review
- Review current service details
- Check current term
- Verify service status
- Assess upgrade eligibility

### Step 3: Upgrade Path Validation
- Verify upgrade path exists
- Check pricing and differences
- Review upgrade restrictions
- Confirm feature compatibility

### Step 4: Prorate Calculation
- Calculate prorate amount
- Apply upgrade pricing
- Factor in any discounts
- Generate prorate invoice

### Step 5: Payment Processing
- Attempt automatic charge
- If failed, request payment
- Process payment successfully
- Record transaction details

### Step 6: Approval Workflow
- Route for approval if required
- Verify all criteria met
- Document approval
- Process upgrade

### Step 7: Product Change
- Update product assignment
- Migrate to new product
- Preserve custom fields
- Update pricing

### Step 8: Server Update
- Modify server account
- Apply new resources
- Enable new features
- Remove old limitations

### Step 9: Configuration
- Apply new settings
- Enable premium features
- Configure new options
- Test functionality

### Step 10: Confirmation
- Send upgrade confirmation
- Detail new service level
- Show billing changes
- Provide updated credentials

## Upgrade Request Options
- Online form submission
- Support ticket request
- Phone request
- Live chat request

## Verification Checklist
- [ ] Request validated
- [ ] Payment processed
- [ ] Product changed
- [ ] Server updated
- [ ] Client confirmed
- [ ] Documentation complete
