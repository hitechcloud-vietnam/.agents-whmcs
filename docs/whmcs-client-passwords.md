# WHMCS Client Passwords

## Overview

Password management in WHMCS handles client authentication credentials including password creation, resets, security requirements, and storage. WHMCS provides secure password handling with encryption and various reset mechanisms.

## Password Configuration

### Accessing Settings

**Configuration > Security > Password Settings**

### Basic Configuration

```php

    'max_length' => 128,
    'require_uppercase' => true,
    'require_lowercase' => true,
    'require_numbers' => true,
    'require_special_chars' => false,
    'allow_whitespace' => false
```

## Password Storage

### Security Implementation

```php
// Secure password storage
[
    'algorithm' => 'bcrypt',           // bcrypt, argon2
    'bcrypt_cost' => 12,                // Computational cost
    'salt' => true,                    // Auto-generate salt
    'storage_format' => 'bcrypt_hash'
]

// Example stored password
// $2y$12$LQv3c1yqBWVHxkd0pHAwAOIRKzQk5Jq0zJ4X7YCK5dT9w5vK3kZHy
```

### Hash Verification

```php
// Verify password against hash
if (password_verify($input, $storedHash)) {
    // Password correct
} else {
    // Password incorrect
}

// Rehash if needed
if (password_needs_rehash($storedHash, PASSWORD_BCRYPT, ['cost' => 12])) {
    // Update stored hash
}
```

## Password History

### Prevent Reuse

```php
// Password history check
[
    'history_enabled' => true,
    'history_count' => 5,            // Remember last 5 passwords
    'prevent_reuse' => true
]

// Check against history
function checkPasswordHistory($newPassword, $userId) {
    $history = getPasswordHistory($userId, 5);
    foreach ($history as $oldHash) {
        if (password_verify($newPassword, $oldHash)) {
            return false; // Cannot reuse
        }
    }
    return true;
}
```

## Password Security Best Practices

### Implementation Guidelines

1. **Use bcrypt/argon2**: Modern secure hashing
2. **Salt passwords**: Unique salt per password
3. **Strength requirements**: Enforce minimum strength
4. **Rate limiting**: Prevent brute force attacks
5. **Secure transmission**: HTTPS only

## Password Breach Detection

### Check Against Breaches

```php
// Check password against known breaches
[
    'check_hibp' => false,           // Have I Been Pwned API
    'block_breached_passwords' => true,
    'notify_on_breach' => true
]

// Using Have I Been Pwned
function checkPasswordBreach($password) {
    $hash = strtoupper(sha1($password));
    $prefix = substr($hash, 0, 5);
    $suffix = substr($hash, 5);
    
    // Check API with prefix
    $response = file_get_contents("https://api.pwnedpasswords.com/range/" . $prefix);
    
    return strpos($response, $suffix) !== false;
}
```
