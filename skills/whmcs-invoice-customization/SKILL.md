# WHMCS Invoice Customization

## Concept Explanation

Invoice customization in WHMCS allows you to modify the appearance and content of invoices generated by the system. This includes changing the layout, adding custom fields, including additional information, applying custom branding, and generating invoices in different formats. Custom invoices can improve professional appearance and meet specific business requirements.

### Customization Areas

- Invoice PDF template design
- Invoice email templates
- Invoice line item formatting
- Tax display configuration
- Payment terms and notes
- Custom footer/header content
- Multi-currency formatting
- Due date and late fee display

## Code Patterns & Templates

### Custom Invoice PDF Generator

```php
<?php
// includes/custom_invoice_pdf.php

use Dompdf\Dompdf;

class CustomInvoicePDF {
    
    protected $invoiceId;
    protected $invoiceData;
    protected $companyLogo;
    
    public function __construct($invoiceId) {
        $this->invoiceId = $invoiceId;
        $this->invoiceData = $this->loadInvoiceData();
        $this->companyLogo = $this->getCompanyLogo();
    }
    
    /**
     * Generate custom PDF invoice
     */
    public function generate() {
        $html = $this->buildHTML();
        
        $dompdf = new Dompdf();
        $dompdf->loadHtml($html);
        $dompdf->setPaper('A4', 'portrait');
        $dompdf->render();
        
        $output = $dompdf->output();
        
        // Save to storage
        $filename = 'invoice_' . $this->invoiceId . '.pdf';
        file_put_contents(INVOICE_DIR . $filename, $output);
        
        return $filename;
    }
    
    /**
     * Build custom HTML template
     */
    protected function buildHTML() {
        $invoice = $this->invoiceData;
        $client = $this->getClientData($invoice['userid']);
        
        $html = '<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <style>
        body { font-family: Helvetica, sans-serif; font-size: 12px; }
        .header { display: table; width: 100%; margin-bottom: 30px; }
        .logo-cell { width: 60%; }
        .invoice-info { text-align: right; }
        .invoice-title { font-size: 24px; color: #333; margin: 0; }
        .info-table { width: 100%; margin-bottom: 20px; }
        .info-table td { vertical-align: top; padding: 5px; }
        .items-table { width: 100%; border-collapse: collapse; margin-bottom: 20px; }
        .items-table th { background: #f5f5f5; padding: 10px; text-align: left; border-bottom: 2px solid #ddd; }
        .items-table td { padding: 10px; border-bottom: 1px solid #eee; }
        .totals-table { width: 300px; margin-left: auto; }
        .totals-table td { padding: 5px 10px; }
        .totals-table .total-row { font-weight: bold; font-size: 14px; border-top: 2px solid #333; }
        .footer { margin-top: 40px; padding-top: 20px; border-top: 1px solid #ddd; font-size: 10px; color: #666; }
        .payment-box { background: #f9f9f9; padding: 15px; margin-top: 20px; border-radius: 5px; }
    </style>
</head>
<body>
    <div class="header">
        <table width="100%">
            <tr>
                <td class="logo-cell">
                    <img src="' . $this->companyLogo . '" alt="Company Logo" style="max-height: 80px;">
                    <br><br>
                    <strong>' . getCompanyName() . '</strong><br>
                    ' . nl2br(getConfiguration('InvoiceTerms')) . '
                </td>
                <td class="invoice-info">
                    <h1 class="invoice-title">INVOICE</h1>
                    <strong>Invoice #:</strong> ' . $invoice['invoicenum'] . '<br>
                    <strong>Date:</strong> ' . fromMySQLDate($invoice['date']) . '<br>
                    <strong>Due Date:</strong> ' . fromMySQLDate($invoice['duedate']) . '<br>
                    <strong>Status:</strong> ' . ucfirst($invoice['status']) . '
                </td>
            </tr>
        </table>
    </div>
    
    <table class="info-table">
        <tr>
            <td width="50%">
                <strong>Bill To:</strong><br>
                ' . $client['firstname'] . ' ' . $client['lastname'] . '<br>
                ' . ($client['companyname'] ? $client['companyname'] . '<br>' : '') . '
                ' . $client['address1'] . '<br>
                ' . $client['city'] . ', ' . $client['state'] . ' ' . $client['postcode'] . '<br>
                ' . $client['country'] . '<br>
                ' . $client['email'] . '
            </td>
            <td width="50%">
                <strong>Ship To:</strong><br>
                ' . ($invoice['reibr_address1'] ?: $client['address1']) . '<br>
                ' . ($invoice['reibr_city'] ?: $client['city']) . ', 
                ' . ($invoice['reibr_state'] ?: $client['state']) . ' 
                ' . ($invoice['reibr_postcode'] ?: $client['postcode']) . '
            </td>
        </tr>
    </table>
    
    ' . $this->buildLineItems() . '
    ' . $this->buildTotals() . '
    ' . $this->buildPaymentBox() . '
    ' . $this->buildFooter() . '
</body>
</html>';
        
        return $html;
    }
    
    /**
     * Build line items table
     */
    protected function buildLineItems() {
        $items = $this->getLineItems();
        
        $html = '<table class="items-table">
            <thead>
                <tr>
                    <th>Description</th>
                    <th width="15%">Qty</th>
                    <th width="15%">Unit Price</th>
                    <th width="15%">Amount</th>
                </tr>
            </thead>
            <tbody>';
        
        foreach ($items as $item) {
            $html .= '<tr>
                <td>
                    <strong>' . $item['description'] . '</strong>';
            
            if ($item['notes']) {
                $html .= '<br><span style="color:#666; font-size:10px;">' . $item['notes'] . '</span>';
            }
            
            $html .= '</td>
                <td>' . $item['qty'] . '</td>
                <td>' . formatCurrency($item['unitprice']) . '</td>
                <td>' . formatCurrency($item['amount']) . '</td>
            </tr>';
        }
        
        $html .= '</tbody></table>';
        return $html;
    }
    
    /**
     * Build totals section
     */
    protected function buildTotals() {
        $invoice = $this->invoiceData;
        
        $html = '<table class="totals-table">
            <tr>
                <td>Subtotal:</td>
                <td align="right">' . formatCurrency($invoice['subtotal']) . '</td>
            </tr>';
        
        if ($invoice['tax'] > 0) {
            $html .= '<tr>
                <td>Tax (' . $invoice['taxrate'] . '%):</td>
                <td align="right">' . formatCurrency($invoice['tax']) . '</td>
            </tr>';
        }
        
        if ($invoice['tax2'] > 0) {
            $html .= '<tr>
                <td>Tax 2 (' . $invoice['taxrate2'] . '%):</td>
                <td align="right">' . formatCurrency($invoice['tax2']) . '</td>
            </tr>';
        }
        
        if ($invoice['credit'] > 0) {
            $html .= '<tr>
                <td>Credit Applied:</td>
                <td align="right">-' . formatCurrency($invoice['credit']) . '</td>
            </tr>';
        }
        
        $html .= '<tr class="total-row">
                <td>Total Due:</td>
                <td align="right">' . formatCurrency($invoice['total']) . '</td>
            </tr>
        </table>';
        
        return $html;
    }
    
    /**
     * Build payment information box
     */
    protected function buildPaymentBox() {
        $gateways = $this->getAvailableGateways();
        
        $html = '<div class="payment-box">
            <strong>Payment Methods</strong><br><br>';
        
        foreach ($gateways as $gateway) {
            $html .= '<img src="' . $gateway['logo'] . '" alt="' . $gateway['name'] . '" 
                style="height:30px; margin-right:10px;">';
        }
        
        $html .= '<br><br><small>Please include invoice number with your payment.</small>';
        $html .= '</div>';
        
        return $html;
    }
    
    /**
     * Build footer
     */
    protected function buildFooter() {
        $customFooter = getConfiguration('InvoiceFooterCustom');
        
        $html = '<div class="footer">
            <p>' . nl2br($customFooter) . '</p>
            <p>Generated on: ' . date('F j, Y g:i A') . '</p>
        </div>';
        
        return $html;
    }
    
    protected function loadInvoiceData() {
        $result = full_query("SELECT * FROM tblinvoices WHERE id = " . (int)$this->invoiceId);
        return mysql_fetch_array($result);
    }
    
    protected function getClientData($clientId) {
        $result = full_query("SELECT * FROM tblclients WHERE id = " . (int)$clientId);
        return mysql_fetch_array($result);
    }
    
    protected function getLineItems() {
        $result = full_query("SELECT * FROM tblinvoiceitems WHERE invoiceid = " . (int)$this->invoiceId);
        $items = [];
        while ($row = mysql_fetch_array($result)) {
            $items[] = $row;
        }
        return $items;
    }
    
    protected function getAvailableGateways() {
        $result = full_query("SELECT * FROM tblpaymentgateways WHERE setting = 'visible' AND value = 'on'");
        $gateways = [];
        while ($row = mysql_fetch_array($result)) {
            $gateways[] = [
                'name' => $row['gateway'],
                'logo' => 'images/gateways/' . strtolower($row['gateway']) . '.png'
            ];
        }
        return $gateways;
    }
    
    protected function getCompanyLogo() {
        return defined('WHMCS_LOGO') ? WHMCS_LOGO : 'images/logo.png';
    }
}
```

### Invoice Custom Field Hook

```php
<?php
// hooks/invoice_custom_fields.php

// Add custom fields to invoice display
add_hook('InvoiceDetailsPagePreOutput', 1, function($vars) {
    $invoiceId = $vars['invoiceid'];
    
    // Get custom fields for this invoice
    $customFields = getCustomFields('invoice', $invoiceId);
    
    if (!empty($customFields)) {
        foreach ($customFields as $field) {
            $vars['custom_fields'][] = [
                'name' => $field['fieldname'],
                'value' => $field['value']
            ];
        }
    }
    
    return $vars;
});

// Hook to modify invoice before creation
add_hook('InvoiceCreationPreEmail', 1, function($vars) {
    $invoiceId = $vars['invoiceid'];
    
    // Add internal notes or references
    update_query('tblinvoices', [
        'admin_notes' => 'Custom notes for invoice #' . $invoiceId
    ], ['id' => $invoiceId]);
    
    return $vars;
});
```

### Dynamic Invoice Notes

```php
<?php
// includes/invoice_notes.php

class InvoiceNoteGenerator {
    
    /**
     * Generate contextual invoice notes
     */
    public static function generateNotes($invoiceId) {
        $invoice = getInvoice($invoiceId);
        $notes = [];
        
        // Add payment terms based on client group
        $clientGroup = getClientGroup($invoice['userid']);
        if ($clientGroup['groupname'] === 'VIP') {
            $notes[] = 'Thank you for being a VIP customer! Net 60 terms apply.';
        }
        
        // Add early payment discount notice
        $daysUntilDue = daysUntil($invoice['duedate']);
        if ($daysUntilDue >= 30) {
            $notes[] = 'Early payment discount: 5% if paid within 10 days';
        }
        
        // Add service renewal notes
        $items = getInvoiceItems($invoiceId);
        foreach ($items as $item) {
            if ($item['type'] === 'Hosting') {
                $service = getService($item['relid']);
                $notes[] = 'Service renews on ' . fromMySQLDate($service['nextduedate']);
            }
        }
        
        return implode("\n", $notes);
    }
    
    /**
     * Add late fee calculation note
     */
    public static function addLateFeeNote($invoiceId, $daysLate) {
        $lateFeeRate = getConfiguration('LateFeePercentage') ?? 2;
        $invoice = getInvoice($invoiceId);
        $lateFee = $invoice['total'] * ($lateFeeRate / 100);
        
        return sprintf(
            'Invoice is %d days overdue. Late fee of %.2f%% ($%s) will be applied.',
            $daysLate,
            $lateFeeRate,
            formatCurrency($lateFee)
        );
    }
}
```

## Step-by-Step Implementation

### 1. Create Custom PDF Template

1. Create `/includes/custom_invoice_pdf.php`
2. Implement the CustomInvoicePDF class
3. Design HTML/CSS template matching your branding
4. Test PDF generation with various invoice types

### 2. Install Hook

```php
// Add to /hooks/custom_invoice_hook.php
add_hook('PdfInvoiceGeneration', 1, function($vars) {
    $pdf = new CustomInvoicePDF($vars['invoiceid']);
    return $pdf->generate();
});
```

### 3. Configure Invoice Settings

Navigate to Configuration > General Settings > Invoices:
- Set default invoice header/footer
- Configure tax display options
- Set payment terms
- Enable/disable invoice numbering

### 4. Create Custom Email Templates

Create email templates for:
- Invoice created
- Invoice paid
- Invoice overdue reminder
- Late fee notice
